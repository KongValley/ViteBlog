✦内置工具类型

TS 内置了一批工具类型（Utility Types），它们就是用映射类型、条件类型拼出来的。配合一份靠谱的 tsconfig.json 和声明文件，才算完整的工程化能力。

ts-07-utility-typesTypeScript
type UserPreview = Pick<User, 'id' | 'name'>

// 更新字段:排除 id,其余转成可选
type UserUpdate = Partial<Omit<User, 'id'>>
把 strict 打开，不是为了让编译器高兴，而是让它在重构时替你记住所有假设。

工具类型不是语法糖，而是团队协作里的「协议」——先定义好类型，再让实现去满足它。
