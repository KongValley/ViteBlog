技术分析的门派很多,但绕不开的第一课都是 K 线。它把一段时间内价格的搏斗结果压缩成一根根"蜡烛",读懂它,就读懂了市场情绪的来龙去脉。

## 一、K 线是什么

一根 K 线记录四个价格:**开盘价、收盘价、最高价、最低价**。按时间周期可以是分钟、日、周、月,新手建议先从日 K 看起。

```text
        │              ← 最高价
      ┌─┴─┐
      │   │            ← 实体:开盘价与收盘价之间
      │   │               阳线(收 > 开)→ 多头获胜
      │   │               阴线(收 < 开)→ 空头获胜
      └─┬─┘
        │              ← 最低价
```

- **实体**:开盘到收盘的距离,代表这段时间多空实际推进的阵地
- **影线**:实体之外的价格波动,代表曾经试探过但没能守住的位置
- **颜色**:国内习惯红涨绿跌(和美股相反),别搞混

一根光头光脚的大阳线(没有影线),说明多头从头压制到尾;而一根长上影线的小实体,说明冲高后被打回来了 —— 同样的涨跌数字,故事完全不同。

## 二、单根 K 线的典型信号

单根 K 线要结合**位置**看才有意义:同样的锤子线,出现在大跌之后是见底信号,出现在横盘中什么都不是。

- **锤子线**:下跌后出现,下影线很长(超过实体两倍),说明空头砸盘被多头接回来了
- **上吊线**:长得和锤子一样,但出现在大涨之后,多头接盘可能是诱多
- **十字星**:开收盘价几乎相同,多空打平。大涨后的十字星 = 警报;横盘中的十字星 = 噪音
- **光头光脚大阴线**:从开盘砸到收盘毫无反抗,空头情绪极端释放

## 三、经典组合形态

单根 K 线是单词,组合形态才是句子。几个最经典的:

| 形态 | 出现位置 | 含义 |
| --- | --- | --- |
| 早晨之星 | 下跌末期 | 三根 K 线:阴线 → 跳空小十字 → 阳线,见底反转 |
| 黄昏之星 | 上涨末期 | 早晨之星的镜像,见顶反转 |
| 乌云盖顶 | 上涨途中 | 阳线后高开阴线,吞掉前日一半以上实体,看跌 |
| 曙光初现 | 下跌途中 | 乌云盖顶的镜像,看涨 |
| 红三兵 | 低位启动 | 三连阳温和上行,多头稳步进场 |
| 三只乌鸦 | 高位 | 三连阴,趋势转弱信号 |

记忆技巧:**反转形态的核心是"力度对比"** —— 前面涨得越猛,后面的阴线吞得越深,反转的置信度越高。

## 四、趋势三要素

K 线形态解决"什么时候变盘",趋势分析解决"往哪个方向做"。

### 1. 趋势方向

- **上升趋势**:高点越来越高,低点也越来越高(台阶向上)
- **下降趋势**:高点越来越低,低点也越来越低
- **震荡**:高低点水平延伸,形态分析在这个阶段基本失效

### 2. 支撑与阻力

前期的成交密集区、前高前低、整数关口,都会形成支撑或阻力。**突破要有验证**:放量站上阻力位三天不回头,才算有效突破;冲上去又跌回来,是假突破。

### 3. 均线系统

均线(MA)是最常用的趋势量化工具。短期均线在长期均线上方且发散向上,叫**多头排列**;反之是**空头排列**。常见的参考组合:MA5(攻击线)、MA20(生命线)、MA60(决策线)。

用代码算一个简单的 N 日均线,几行就够了:

```js
// 计算 N 日简单移动平均线(SMA)
function sma(closes, n) {
  return closes.map((_, i) => {
    if (i < n - 1) return null // 数据不足 n 天,返回空
    const window = closes.slice(i - n + 1, i + 1)
    return window.reduce((sum, price) => sum + price, 0) / n
  })
}

const ma5 = sma([10.2, 10.8, 11.1, 10.9, 11.5, 11.8], 5)
console.log(ma5) // [null, null, null, null, 10.9, 11.22]
```

EMA(指数均线)给近期价格更高权重,反应更灵敏,主流行情软件默认的 MA 通常是 EMA。

## 五、量价配合

价格是结果,成交量是燃料:

- **放量上涨**:有增量资金,趋势健康
- **缩量上涨**:存量博弈,警惕冲高乏力
- **放量下跌**:恐慌抛售,可能加速赶底
- **缩量回调**:抛压不大,上升趋势中的健康整理

"突破 + 放量"是技术分析里置信度最高的组合信号之一。

## 六、几点提醒

1. **K 线是概率,不是预言**。任何形态都只是提高胜率的统计倾向,不存在百分之百
2. **周期越大越可靠**:日 K 的信号比 5 分钟 K 可靠得多,周 K 更甚
3. **不要孤立看单根 K 线**:位置、趋势、成交量、大盘环境,缺一不可
4. **先想止损再想盈利**:技术分析给出的是入场理由,而活下来靠的是出场纪律

技术分析是地图,不是自动驾驶。愿我们都能在市场里保持敬畏,慢慢变富。
